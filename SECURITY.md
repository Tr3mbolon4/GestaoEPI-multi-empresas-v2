# Politica de seguranca

## Dados que nao devem ser versionados

- Arquivos `.env` reais.
- Senhas, tokens, chaves e credenciais.
- Backups de banco e dumps.
- Fotos reais, uploads e evidencias de entrega.
- CPFs, CNPJs reais, telefones, e-mails internos e dados de colaboradores.
- Dados biometricos ou templates faciais.
- PRDs, relatorios de teste e artefatos internos de agente.

## Pendencias

- Limpar historico Git antigo se aprovado.
- Confirmar se esta versao antiga deve permanecer publica.
- Rotacionar segredos que possam ter sido usados fora de ambiente demonstrativo.
- Decidir se o repositorio deve virar apenas documentacao historica.
